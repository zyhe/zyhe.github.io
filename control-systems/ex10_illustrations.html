Task 10.1 · Open loop vs. P vs. PI

G(s) = 10 (0.1s + 1)s² + 10s + 1  H = 0.5   r(t) = 50·σ(t)

Final value theorem: for step inputs e∞ = Ger(0)·rref + Ged(0)·dc. It only applies if the closed loop is asymptotically stable.

Open loop uses Ko = 1/A: perfect tracking only on paper, and the disturbance passes straight through. P control divides the error by 1 + kA. An integrator in K(s) makes Ger(0) = Ged(0) = 0, so steps leave no error. A ramp needs a double integrator.

Task 10.4 · PID zeros and the root locus

G(s) = 1(s + 10)(s + 2)²

A PID controller adds one pole at 0 and two zeros. The zeros pull the branches; the asymptote centroid σ = (Σ poles − Σ zeros)/(np − nz) decides whether the loop survives high gain.

Settling time: last time the response leaves the ±1 % band around its own final value. Overshoot is relative to that final value, so P control can "settle" while still missing the reference.
