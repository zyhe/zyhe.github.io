What a point on the Bode plot means

Send a sinusoid into an asymptotically stable LTI system. Once the transient has died out, the output is a sinusoid at the same frequency, with amplitude |G(iω)| and phase shift arg G(iω).

G(s) = 1s² + 0.6s + 1  u(t) = sin(ωt)

The Bode plot is a catalogue of such experiments, one per frequency. The steady-state formula needs asymptotic stability; for an unstable system the Bode plot is only a plot of the complex function G(iω).

Task 9.3 iv, v · BIBO vs. internal stability

Internal stability: eigenvalues of A. BIBO stability: poles of G(s). They agree unless an unstable pole is cancelled by a zero, which hides it from the output.

A = −1021 B = 0−1 C = −13 → G(s) = −3s + 1(s+1)(s−1)

A = −1501 B = 11 C = 10 → G(s) = s − 1(s+1)(s−1) = 1s + 1
